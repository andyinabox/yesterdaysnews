# [yesterday's news](/)

The videos you are seeing are a random reshuffling of news clips from the day before today. The text is generated from the english subtitles for those videos, alongside a journal of mine from late October to early November 2016. The video order is purely random, but the text follows its own internal logic. 

If you're interested, you can find the source code for this project [here](https://gitlab.com/andyinabox/yesterdaysnews/-/blob/main/README.md).
